# Chakaram_V_1
# சக்கரம் • CHAKARAM 3D

### Traditional Indian Chowka Bara / Katte Mane Board Game

Chakaram 3D is a digital implementation of the traditional Indian
Chowka Bara / Katte Mane board game. The game combines traditional
gameplay with a modern 3D visual interface, allowing players to
experience the game digitally.

## Version 1.0

Version 1 focuses on the basic game setup, board selection, player
configuration, cowrie-shell selection, and the core gameplay interface.

## Features

- Traditional Chowka Bara / Katte Mane gameplay
- 5 × 5 Classic Board
- 7 × 7 Grand Board
- 1 Player vs AI mode
- 2 Players Local mode
- 4 Players Local mode
- 4 Cowrie Shell option
- 6 Cowrie Shell option
- 3D board presentation
- Top-Down and Cinematic camera views
- Traditional-inspired visual design
- Player status display
- Turn indicator
- Match log
- Cowrie-shell rolling interface
- New Match / Setup option
- Sound control

## Board Options

### Classic 5 × 5 Matrix
- 25 cells
- 4 Safe Houses

### Grand 7 × 7 Matrix
- 49 cells
- 12 Safe Houses

## Game Modes

### 1 Player vs AI
A single human player competes against three AI-controlled players.

### 2 Players Local
Two players can play locally against each other.

### 4 Players Local
Four players can participate in a local Pass & Play match.

## Cowrie Shell Options

The game provides two shell configurations:

### 6 Chozhi Shells
Possible rolls:
1, 2, 3, 4, 5, 6

### 4 Chozhi Shells
Possible rolls:
1, 2, 3, 4, 8

## Gameplay Interface

The gameplay screen provides:

- Current player and turn information
- Player status panels
- Board and token positions
- Cowrie-shell display
- Roll Chozhi button
- Match log
- Game setup / new match controls
- Sound control
- Camera view controls

## Objective

The main objective is to move the player's tokens through the
designated board path and successfully complete the required journey
before the opponents.

## Technology / Design

The project uses a modern digital game interface inspired by the
traditional visual identity of Chowka Bara. The interface uses a
dark background with gold highlights and traditional Indian-inspired
visual elements.
